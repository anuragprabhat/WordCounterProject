# Word Counter Project

A simple Java-based Word Counter application with a graphical user interface built using Java Swing.

## Features
- Count the total number of words.
- Count characters in the given text.
- Simple and user-friendly GUI.
- Real-time text processing.

## Technologies Used
- Java
- Java Swing
- IntelliJ IDEA

## Project Files
- **Main.java** – Main entry point of the application.
- **WordCounter.java** – Contains the word counting logic.
- **WordCounterGUI.java** – Handles the graphical user interface.

## How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Run `Main.java`.
